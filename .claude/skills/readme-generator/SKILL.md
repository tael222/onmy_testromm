# README Generator

프로그램 아키텍처를 분석하고 표준 양식의 README 문서를 생성하는 스킬.

## 워크플로우

### 1단계: 프로젝트 구조 분석

```bash
# 디렉토리 구조 파악
find . -type f -name "*.py" -o -name "*.cs" -o -name "*.ts" -o -name "*.js" | head -50
tree -L 3 -I "node_modules|__pycache__|.git|dist|build"
```

분석 대상:
- 진입점 파일 (main, index, __init__)
- 핵심 모듈/클래스 구조
- 설정 파일 (package.json, setup.py, requirements.txt)
- 기존 문서 (README, docs/)

### 2단계: 핵심 코드 분석

각 주요 파일에서 추출:
- 클래스/함수 시그니처
- docstring 및 주석
- import 관계 (의존성 그래프)
- public API

### 3단계: README 작성

`references/template.md` 양식 참조하여 다음 섹션 작성:

```markdown
# [프로젝트명]: [한줄 설명]

[프로젝트 개요 2-3문장]

## 목차
- 링크 목록 (자동 생성)

## 설치 방법
- 패키지 매니저 명령어
- 요구사항

## 빠른 시작
- 핵심 사용법 코드 예시 (실행 가능한 최소 예제)

## 핵심 개념
- 주요 원칙/패턴 설명
- 표로 정리된 핵심 요소

## 내부 구조 개요
- 디렉토리 트리
- 각 파일/폴더 역할 설명

## 주요 클래스/모듈
- 상세 API 문서
- 사용 예시

## 추가 정보
- 시스템 요구사항
- 주요 기능 체크리스트
- 문의처
```

## 작성 원칙

1. **구체적 예시 우선**: 설명보다 동작하는 코드 예시 제공
2. **점진적 복잡도**: 간단한 예시 → 고급 사용법 순서
3. **표 활용**: 컨테이너, 타입, 옵션 등은 표로 정리
4. **이모지 제한적 사용**: 💡 팁, ⚠️ 주의, ✅ 기능 목록 정도만
5. **한글 우선**: 기술 용어는 영문 병기

## 출력

- `/mnt/user-data/outputs/README.md`에 최종 문서 저장
- 마크다운 형식
