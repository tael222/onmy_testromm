# 📋 Product Requirements Document (PRD)

## ReadAlongBuddy - 아이와 함께하는 마법의 책 읽기 친구

| 항목 | 내용 |
|------|------|
| **문서 버전** | 1.1 |
| **최종 수정일** | 2025-12-30 |
| **상태** | Active |

---

## 1. 개요 (Overview)

### 1.1 제품 요약

**ReadAlongBuddy**는 어린이가 책 페이지를 촬영하면 AI가 텍스트를 인식하고 음성으로 읽어주는 웹 애플리케이션입니다.

### 1.2 배경 및 동기

- 맞벌이 가정 증가로 부모가 아이에게 책을 읽어줄 시간 부족
- 어린이의 독서 습관 형성에 음성 지원이 효과적
- 기존 오디오북은 특정 책에 한정되어 있음
- 아이가 가진 **어떤 책이든** 읽어줄 수 있는 솔루션 필요

### 1.3 제품 비전

> 모든 어린이가 언제 어디서나 책 읽는 즐거움을 경험할 수 있도록 돕는다.

## 2. 문제 정의 (Problem Statement)

### 2.1 현재 상황의 문제점

| 문제 | 설명 |
|------|------|
| **시간 부족** | 부모가 매일 책을 읽어줄 시간이 부족함 |
| **발음 불확실** | 부모가 영어 발음에 자신이 없는 경우 |
| **오디오북 한계** | 특정 책만 오디오북으로 제공됨 |
| **접근성** | 시각 장애 아동의 책 접근성 제한 |

### 2.2 해결 방안

**ReadAlongBuddy**가 제공하는 해결책:

1. **즉시 읽어주기**: 어떤 책이든 사진만 찍으면 바로 읽어줌
2. **정확한 발음**: AI 기반 자연스럽고 정확한 발음 제공
3. **24시간 이용**: 언제든지 사용 가능
4. **무료 서비스**: 경제적 부담 없이 이용

## 4. 핵심 기능 요구사항 (Functional Requirements)

### 4.1 MVP (최소 기능 제품) 기능

#### FR-001: 이미지 입력

| 항목 | 내용 |
|------|------|
| **기능명** | 이미지 업로드/촬영 |
| **설명** | 사용자가 책 페이지 이미지를 제공할 수 있음 |
| **입력** | 카메라 촬영 또는 갤러리에서 이미지 선택 |
| **출력** | 미리보기 화면에 이미지 표시 |
| **우선순위** | P0 (필수) |

**세부 요구사항:**
- [ ] 이미지 파일 업로드 지원 (JPG, PNG)
- [ ] 웹캠/카메라 촬영 지원
- [ ] 이미지 미리보기 제공
- [ ] 이미지 재촬영/재선택 가능

#### FR-002: 텍스트 인식 (OCR)

| 항목 | 내용 |
|------|------|
| **기능명** | OCR 텍스트 추출 |
| **설명** | 이미지에서 텍스트를 자동으로 인식하여 추출 |
| **입력** | 책 페이지 이미지 |
| **출력** | 인식된 텍스트 문자열 |
| **우선순위** | P0 (필수) |

**세부 요구사항:**
- [ ] 영어 텍스트 인식 (MVP)
- [ ] 한글 텍스트 인식 (Phase 2)
- [ ] 인식 결과 화면에 표시
- [ ] 텍스트 인식 정확도 90% 이상

#### FR-003: 음성 합성 (TTS)

| 항목 | 내용 |
|------|------|
| **기능명** | 텍스트 음성 읽기 |
| **설명** | 인식된 텍스트를 자연스러운 음성으로 읽어줌 |
| **입력** | 텍스트 문자열 |
| **출력** | 음성 오디오 재생 |
| **우선순위** | P0 (필수) |

**세부 요구사항:**
- [ ] 자연스러운 영어 발음 (MVP)
- [ ] 재생/일시정지 컨트롤
- [ ] 음성 속도 조절 (느리게/보통/빠르게)
- [ ] 아이 친화적인 음성 톤

#### FR-004: 텍스트 편집

| 항목 | 내용 |
|------|------|
| **기능명** | 인식 텍스트 수정 |
| **설명** | OCR 오인식 텍스트를 사용자가 수정 가능 |
| **입력** | 사용자 텍스트 수정 |
| **출력** | 수정된 텍스트로 TTS 재실행 |
| **우선순위** | P1 (중요) |

## 6. 사용자 시나리오 (User Scenarios)

### 6.1 기본 사용 시나리오

```
시나리오: 민지가 영어 그림책을 읽고 싶을 때

1. 민지가 ReadAlongBuddy 웹사이트에 접속한다
2. "책 읽기 시작" 버튼을 누른다
3. 영어 그림책의 한 페이지를 카메라로 촬영한다
4. 화면에 촬영된 이미지가 표시된다
5. "읽어줘!" 버튼을 누른다
6. 잠시 후 텍스트가 화면에 표시된다
7. 자동으로 음성이 재생되며 책을 읽어준다
8. 민지는 음성을 들으며 그림책을 본다
9. 다음 페이지를 읽고 싶으면 "새 페이지" 버튼을 누른다
```

## 8. 제약사항 및 가정 (Constraints & Assumptions)

### 8.1 제약사항

| 유형 | 제약사항 |
|------|----------|
| **비용** | 모든 서비스는 무료로 운영 가능해야 함 |
| **기술** | Python/Streamlit 기반으로 개발 |
| **인프라** | 무료 호스팅 서비스 사용 (Streamlit Cloud) |
| **언어** | MVP는 영어만 지원 |
| **저작권** | 책 콘텐츠 공유/저장/내보내기 기능 제한 필수 |

### 8.2 가정

| 가정 | 설명 |
|------|------|
| 인터넷 연결 | 사용자는 안정적인 인터넷 연결 환경에 있음 |
| 카메라 품질 | 일반 스마트폰 카메라 수준의 이미지 품질 |
| 책 상태 | 책 페이지가 심하게 구겨지거나 훼손되지 않음 |
| 글씨 크기 | 어린이 도서 수준의 적당한 크기의 글씨 |

## 9. 범위 외 (Out of Scope)

MVP에서 **포함하지 않는** 기능:

| 기능 | 제외 이유 |
|------|----------|
| 회원가입/로그인 | MVP 단순화 |
| 손글씨 인식 | 기술적 복잡도 |
